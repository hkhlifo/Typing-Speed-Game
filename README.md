# Typing Speed Game

A full-stack typing speed game where users complete a sequence of randomly generated alphabets and compete for the fastest completion time.

## Planned Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Backend
- Bun
- TypeScript
- GraphQL Yoga
- PostgreSQL
- Prisma

### Infrastructure
- Docker Compose
